# CipherHub Beta · 暗号/关键词查询中心（在线表格 1:1 实时同步版）

基于 CipherHub 打造的 **纯静态、零构建步骤（Live Server 直接打开）** Beta 版本，支持在后台绑定 Google 在线表格，实现在线表格与前端页面 **1:1 实时同步统一**。

## 1. 在线表格结构与固定排序规范

表格内容与前台展示严格 **一一对应**，第一行表头固定为：

| 列位置 | A1 | B1 | C1 |
| :--- | :--- | :--- | :--- |
| **表头内容** | `姓名` | `关键词` | `模板` |

**固定模板拼接顺序（从上往下排列，不会乱序）：**
1. `番号`
2. `聊天`
3. `对比`
4. `任务`
5. `新模版`
6. `备用`
7. `备用 2`

> 即：先放完「番号」表所有人，再放「聊天」表的，接着是「对比、任务、新模版、备用、备用 2」。无论是在线表格拉取还是后台编辑写回，都会严格按此顺序对齐。

## 2. 目录结构（纯静态，无构建步骤）

- `index.html`：主页面（含前台查询、7 大模板速览、1:1 在线表格视图及内置管理后台，可直接用 VS Code Live Server 打开）
- `css/style.css`：完整样式表
- `js/data.js`：默认配置、7 大模板固定顺序定义及初始示例数据
- `js/sheet-sync.js`：在线表格实时同步引擎（支持 Google Apps Script Web App 双向读写 + Google Sheets GViz JSONP 免脚本直连拉取）
- `js/app.js`：前台搜索、模板筛选、卡片视图与 1:1 表格视图交互
- `js/admin.js`：内置管理后台（连点左上角 Logo 5 次或点击顶栏「⚙️ 后台 / 绑定表格」进入，默认口令 `admin123`）
- `apps-script/Code.gs`：配套 Google Apps Script 云端脚本代码
